# สมัครเอง + ทดลองใช้ 30 วัน + ชำระเองในแอป

ใช้เฉพาะบริษัทที่สมัครจากหน้าเว็บ (`companies.self_serve = 1`) ลูกค้าที่ KSS ตั้งให้เองไม่ได้รับผลกระทบ (ไม่ถูกล็อก ใช้ลิงก์ชำระจากหน้าบริษัทตามเดิม)

## Flow
1. หน้าเข้าสู่ระบบ → "ทดลองใช้ฟรี 30 วัน" → ฟอร์ม (ชื่อร้าน ผู้ติดต่อ อีเมล เบอร์ รหัสผ่าน จำนวนสาขา ใช้ FMH ไหม ความยินยอม)
2. ล็อกอินก่อนอนุมัติ → "รอทีม KSS อนุมัติ"
3. Admin Console → 🧾 สมัครเอง / ทดลองใช้ (มีตัวเลขรออนุมัติ) → อนุมัติ (กดสองครั้ง) → สร้างบริษัทสถานะ trial, ข้อมูลตัวอย่าง, Dashboard "ภาพรวมจัดซื้อ" 7 widget, ผู้ใช้ company_admin ด้วยรหัสผ่านที่ลูกค้าตั้ง **ระบบไม่ส่งอีเมล — ทีมต้องแจ้งลูกค้าเอง**
4. ทดลองใช้: แถบบนบอกวันที่เหลือ + ปุ่ม "ใส่ FMH API key" (ใส่แล้วสลับเป็นข้อมูลจริงทันที) + "ดูแพ็กเกจ"
5. ✎ จัดการ Dashboard → แพ็กเกจและการชำระเงิน: รายเดือน / รายปี (ราคาจากหน้า KSS) → PromptPay QR (Omise) → ต่ออายุจาก max(วันนี้, วันหมดอายุเดิม)
6. หมดทดลอง (วันถัดจากวันหมด) หรือหมดแพ็กเกจ + ผ่อนผัน 3 วัน → **ล็อก**: ล็อกอินได้ เห็นแค่หน้าชำระเงิน API อื่นตอบ 402 จ่ายแล้วปลดล็อกทันที
7. ล็อกครบ 60 วัน → ทีม KSS กด "ลบข้อมูล" ได้ (ข้อมูล FMH ไฟล์อัปโหลด การตั้งค่า LINE; บัญชีและ Dashboard ยังอยู่) ระบบไม่ลบเอง

## สวิตช์ (Railway variables)
| ตัวแปร | ค่าเริ่มต้น | ความหมาย |
|---|---|---|
| `SELF_SIGNUP` | on (ปิดบน production ถ้าไม่ตั้ง) | `on` เพื่อเปิดรับสมัครบน production |
| `TRIAL_DAYS` | 30 | วันทดลองใช้ |
| `SELF_SERVE_GRACE_DAYS` | 3 | ผ่อนผันหลังแพ็กเกจที่จ่ายแล้วหมดอายุ (ทดลองใช้ไม่มีผ่อนผัน) |
| `LOCK_RETENTION_DAYS` | 60 | ลบข้อมูลได้เมื่อล็อกครบกี่วัน |
| `OMISE_PAYMENTS` | ดู docs/billing.md | ถ้าปิด ลูกค้าจะเห็นให้ติดต่อ KSS เพื่อโอน |

ราคา: Admin Console → 🧾 → ราคาแพ็กเกจ (เว้นว่าง = ไม่เปิดขาย) ไม่มีราคาในโค้ด

## ชำระโดยการโอน (เมื่อ Omise ปิด)
ทีม KSS แก้วันหมดอายุที่หน้าบริษัท และเปลี่ยนสถานะเป็น "ใช้งาน" (active) เอง ถ้ายังเป็น trial ระบบจะถือว่ายังทดลองใช้ (ไม่มีผ่อนผัน และแถบบนยังเขียนว่าทดลองใช้)
