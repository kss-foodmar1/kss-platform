# LINE bot สำหรับกลุ่มผู้บริหาร (ต้นแบบ)

แจ้ง "สาขาที่ควรตรวจสอบ" จากรายงานตรวจสาขา เข้ากลุ่ม LINE ของผู้บริหาร แต่ละบริษัทใช้ LINE Official Account (OA) ของตัวเอง
KSS ไม่ถือบอทกลาง และ token ถูกเก็บเข้ารหัสด้วย `ENCRYPTION_KEY` (ไม่เคยถูกส่งกลับมาที่หน้าจอ)

## ตั้งค่า (ทำครั้งเดียวต่อบริษัท)
1. LINE Developers → สร้าง Provider → Messaging API channel (หรือเปิด Messaging API จาก OA ที่มีอยู่)
2. แท็บ **Messaging API**: เปิด **Allow bot to join group chats**, ปิด Auto-reply / Greeting ใน LINE Official Account Manager
3. คัดลอก **Channel secret** (แท็บ Basic settings) และออก **Channel access token (long-lived)** (แท็บ Messaging API)
4. Admin → บริษัท → **LINE แจ้งเตือนผู้บริหาร**: วางทั้งสองค่า กดบันทึก
5. คัดลอก **Webhook URL** จากหน้าเดียวกันไปใส่ใน LINE Developers → Webhook URL → เปิด **Use webhook** → Verify
6. เชิญบอทเข้ากลุ่ม LINE ผู้บริหาร แล้วให้ใครสักคนพิมพ์ข้อความ 1 ข้อความ → บอทตอบว่าเชื่อมแล้ว (กลุ่มนี้ถูกผูกกับบริษัท)
7. กด **ส่งข้อความทดสอบ** แล้วกด **ส่งสรุปสาขาตอนนี้** ติ๊ก **ส่งแจ้งเตือนอัตโนมัติ** เมื่อพร้อม

## พฤติกรรม
- ผูกกับกลุ่มแรกที่คุยกับบอท กลุ่มอื่นที่เชิญบอทเข้าไปจะถูกเมินทั้งหมด (ไม่ตอบ ไม่ส่งข้อมูล) ยกเลิกการผูกได้ในหน้า Admin
- พิมพ์ **สถานะ** ในกลุ่ม → บอทตอบสรุปสาขาที่ควรตรวจ (reply message ไม่นับโควต้า)
- ทุกวัน 08:30 (Asia/Bangkok) ส่งการ์ดสรุปเมื่อ มีสาขาที่ "ควรตรวจ" และรายการ **เปลี่ยน** จากครั้งก่อน (กันส่งซ้ำ → ประหยัดโควต้า push message)
- ข้อความเป็นถ้อยคำ "ควรตรวจสอบ" และระบุว่าเป็นสัญญาณ ไม่ใช่ข้อสรุป

## ที่ยังไม่รู้ / ต้องทดสอบกับ OA จริง
- ข้อความ push เข้ากลุ่มนับโควต้า 1 ต่อกลุ่ม หรือต่อสมาชิก (ดูตัวนับใน OA Manager หลังส่งทดสอบ)
- ราคาแพ็กเกจ OA ไทยปัจจุบัน — ยืนยันที่หน้าทางการของ LINE ก่อนใช้กับลูกค้า
- Flex message ทดสอบกับ mock เท่านั้น (ตรวจโครงสร้าง) ยังไม่เคยแสดงผลบน LINE จริง

ทดสอบ: `node scripts/test-line.js` (ใช้ mock ของ LINE API ไม่ต้องมีบัญชีจริง)
