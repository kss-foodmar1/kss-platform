# LINE bot สำหรับกลุ่มผู้บริหาร (ต้นแบบ)

แจ้ง "สาขาที่ควรตรวจสอบ" จากรายงานตรวจสาขา เข้ากลุ่ม LINE ของผู้บริหาร แต่ละบริษัทใช้ LINE Official Account (OA) ของตัวเอง
KSS ไม่ถือบอทกลาง และ token ถูกเก็บเข้ารหัสด้วย `ENCRYPTION_KEY` (ไม่เคยถูกส่งกลับมาที่หน้าจอ)

## ตั้งค่า (ทำครั้งเดียวต่อบริษัท)
1. LINE Developers → สร้าง Provider → Messaging API channel (หรือเปิด Messaging API จาก OA ที่มีอยู่)
2. แท็บ **Messaging API**: เปิด **Allow bot to join group chats**, ปิด Auto-reply / Greeting ใน LINE Official Account Manager
3. คัดลอก **Channel secret** (แท็บ Basic settings) และออก **Channel access token (long-lived)** (แท็บ Messaging API)
4. Admin → บริษัท → **LINE แจ้งเตือนผู้บริหาร**: วางทั้งสองค่า กดบันทึก
5. คัดลอก **Webhook URL** จากหน้าเดียวกันไปใส่ใน LINE Developers → Webhook URL → เปิด **Use webhook** → Verify
6. เชิญบอทเข้ากลุ่ม LINE ผู้บริหาร แล้วให้ใครสักคนพิมพ์ข้อความ 1 ข้อความ → บอทตอบว่าเชื่อมแล้ว (กลุ่มนี้ถูกผูกกับบริษัท)
7. กด **ส่งข้อความทดสอบ** แล้วกด **ส่งสรุปสาขาตอนนี้** ติ๊ก **ส่งแจ้งเตือนอัตโนมัติ** เมื่อพร้อม

## Widget ตัวเตือน (lib/alerts.js)
แยกจาก widget วิเคราะห์: ตอบ "วันนี้มีอะไรต้องจัดการ" ด้วยช่วงเวลาตายตัวของตัวเอง ไม่เปลี่ยนตามตัวกรองวันที่ของหน้า
ผลชุดเดียวกัน (ตาราง `alert_events`) ใช้ทั้งแสดงบน Dashboard และส่ง LINE ตัวเลขจึงตรงกันเสมอ

| ตัวเตือน | source | จังหวะ | กติกา |
|---|---|---|---|
| ราคาซื้อวัตถุดิบขึ้นผิดปกติ | `watch-price` | รายวัน | วันสั่งล่าสุดใน 3 วัน เทียบราคาเฉลี่ย 90 วันก่อนหน้า (สินค้า + ซัพพลายเออร์ + หน่วยเดียวกัน) เกิน 10% และจ่ายเกิน ฿300 (ปรับได้) |
| PO ค้างไม่ปิด | `watch-po` | รายวัน | เลยวันนัดส่งเกิน 7 วันแต่ไม่มี GRN หรือมี GRN เกิน 7 วันแต่ยังไม่ COMPLETED (ปรับจำนวนวันได้) · LINE สรุปเป็นจำนวนใบ มูลค่า เก่าสุด + 3 ใบที่ค้างนานสุด เตือนซ้ำทุกสัปดาห์ที่ยังค้าง |
| SO ครัวกลางค้างไม่ปิด | `watch-so` | รายวัน | เหมือน PO แต่ใช้ DO แทน GRN |
| สาขาซื้อจากครัวกลางน้อยผิดปกติ | `watch-ck` | รายเดือน | "ควรตรวจ" จากรายงานตรวจสาขา (ต่ำกว่า 85% ของค่ากลาง 3 เดือนติด) |

- สถานะ: ใหม่ / ต่อเนื่อง / จบแล้ว (แสดงย้อนหลัง 14 วัน) · ระดับ: สูง / กลาง · ผลกระทบเป็นบาท
- เพิ่มตัวเตือนใหม่: เพิ่มใน `WATCHERS` (lib/alerts.js) + source `watch-*` ใน FMH_REPORTS (`localBuild: 'alerts'`, `inputs`) + template หมวด `Alerts`
- ทดสอบ: `node scripts/test-alerts.js`

## พฤติกรรม
- ผูกกับกลุ่มแรกที่คุยกับบอท กลุ่มอื่นที่เชิญบอทเข้าไปจะถูกเมินทั้งหมด (ไม่ตอบ ไม่ส่งข้อมูล) ยกเลิกการผูกได้ในหน้า Admin
- พิมพ์ **สถานะ** ในกลุ่ม → บอทตอบทุกเรื่องที่เปิดอยู่จากทุกตัวเตือน (reply message ไม่นับโควต้า)
- ทุกวัน 08:30 (Asia/Bangkok) ส่งการ์ด "สิ่งที่ควรดูวันนี้" 1 ข้อความ รวมทุกตัวเตือนที่เปิดส่ง LINE ไว้ เฉพาะเรื่อง **ใหม่หรือแย่ลง** (ตัวเตือนละไม่เกิน 3 รายการ ที่เหลือบอกจำนวน)
- ข้อจำกัด: รายงาน FMH ไม่มีชื่อผู้สร้างเอกสาร ตัวเตือน PO/SO จึงระบุได้ถึงสาขา ซัพพลายเออร์ ลูกค้า ไม่ถึงตัวพนักงาน และไม่เห็น PO สถานะ PENDING (แอปดึงเฉพาะสถานะที่ผูกพันแล้ว)
- เลือกตัวเตือนที่ส่ง LINE และปรับเกณฑ์ได้ในแผงเดียวกัน (เกณฑ์ชุดเดียวกับ widget)
- ข้อความเป็นถ้อยคำ "ควรตรวจสอบ" และระบุว่าเป็นสัญญาณ ไม่ใช่ข้อสรุป

## ที่ยังไม่รู้ / ต้องทดสอบกับ OA จริง
- ข้อความ push เข้ากลุ่มนับโควต้า 1 ต่อกลุ่ม หรือต่อสมาชิก (ดูตัวนับใน OA Manager หลังส่งทดสอบ)
- ราคาแพ็กเกจ OA ไทยปัจจุบัน — ยืนยันที่หน้าทางการของ LINE ก่อนใช้กับลูกค้า
- Flex message ทดสอบกับ mock เท่านั้น (ตรวจโครงสร้าง) ยังไม่เคยแสดงผลบน LINE จริง

ทดสอบ: `node scripts/test-line.js` (ใช้ mock ของ LINE API ไม่ต้องมีบัญชีจริง)
